# Diseño Web con Astro y Tailwind

Curso de la carrera de Computación e Informática del IESTP John A. Mackay (Rioja), V ciclo. En ocho semanas
construyes y publicas el sitio web de un negocio real de tu entorno, con HTML semántico, CSS con Tailwind y
JavaScript, usando Astro.

## Empieza aquí

1. Lee la [guía de la semana 1](guias/semana-1.md).
2. Crea tu repositorio desde la plantilla **https://github.com/NiloSalvador/diseno-web-ijam-plantilla**.

## Cómo es cada semana

1. **Guía** con los pasos y el código para copiar.
2. **Dos vídeos cortos** donde se construye el sitio del ejemplo, Café Orquídea.
3. **Práctica en tu propio sitio.** El revisor (`npm run revisar -- N`, con el número de la semana) te dice qué
   falta antes de entregar.
4. **Entrega** del enlace de tu repositorio en el aula y un **cuestionario** de cinco preguntas.
5. **Dudas** por el chat del curso en el aula.

## Reglas del proyecto

- Usa solo datos públicos del negocio y pide permiso al dueño para usar sus fotos y su logo, porque tu repositorio
  es público.
- Puedes usar inteligencia artificial como ayuda. En la sustentación explicarás tu código y harás un cambio en vivo,
  así que entiende cada línea que agregues.
- Haz commits seguidos, porque el historial muestra cómo avanzaste.
